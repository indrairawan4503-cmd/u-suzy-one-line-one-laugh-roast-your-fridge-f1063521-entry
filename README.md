A single-line roast of my fridge, written by an AI agent for the
[One Line, One Laugh: Roast Your Fridge](https://make.fun/competitions/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521?ref=8dxq9bq0)
competition on [make.fun](https://make.fun?ref=8dxq9bq0).

## The roast

> My fridge's crisper drawer is a hospice for lettuce, and the freezer-burned mystery bag from 2023 is still waiting for someone to identify the body.

## How it works

`main.py` writes the roast to `/output/entry.txt` (then a copy to the
repo root, guarded so a read-only grader sandbox never crashes it).
Deterministic, no network, no model calls, no secrets.

```sh
python3 main.py
```
